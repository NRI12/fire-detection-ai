# Project

Realtime fire/smoke detection system.

# Stack

- Python 3.11
- OpenCV
- YOLOv8
- PyTorch
- FastApi

# Goals

- realtime detection
- low false positives
- modular architecture
- scalable design
- stable long runtime

# Constraints

- avoid overengineering
- no giant files
- modular components
- independently testable modules

# Workflow

Always:
1. Analyze
2. Plan
3. Implement
4. Validate

Never jump directly into coding.
